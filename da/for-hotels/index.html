FAQ

Almindelige spørgsmål

Virker det med vores hotelhjemmeside?+

Ja — WebAssist virker med alle typer hjemmesider inkl. WordPress, Wix, Squarespace og specialbyggede hotelhjemmesider. Under onboarding forbinder vi os til din eksisterende side.

Kan vi opdatere sæsonpriser hurtigt?+

Ja. Send de nye priser på WhatsApp, og vi opdaterer hjemmesiden samme dag. Du modtager en bekræftelse. Perfekt til sommer-, jul- og nytårspriser.

Kan vi annoncere events og pakketilbud?+

Absolut. Julefrokost, nytårsaften, bryllupspakker, weekendtilbud — send os tilbuddet og vi sætter det live samme dag, så det er der når kunderne søger.

Kan vi opdatere restaurantmenuen?+

Ja. Send den nye menu eller de ændrede retter på WhatsApp, og vi opdaterer restaurantsiden samme dag. Perfekt til sæsonmenuer og ugentlige ændringer.

Kan vi opsige til enhver tid?+

Ja. Månedlige abonnementer kan opsiges med 30 dages varsel. Der er ingen langsigtede kontrakter.
