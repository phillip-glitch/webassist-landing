FAQ

Almindelige spørgsmål

Virker det med min arkitektur-hjemmeside?+

Ja — WebAssist virker med alle typer hjemmesider. Uanset om det er WordPress, Webflow, Wix eller specialbygget site.

Hvor hurtig er opdatering af projekter?+

Normalt samme dag. Send blot "Tilføj projekt: [navn]" på WhatsApp og vi opdaterer det på din portfolio.

Kan jeg skifte billeder for gamle projekter?+

Ja. Send os de nye billeder på WhatsApp og vi opdaterer dem inden for samme dag.

Hvordan fungerer kundehenvisninger?+

Send navn, firma og citatet på WhatsApp, og vi tilføjer det til det rigtige projekt på din hjemmeside.

Kan jeg opsige når som helst?+

Ja. Du kan opsige med 30 dages varsel. Ingen langsigtede kontrakter.
